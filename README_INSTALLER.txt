COMO CRIAR O INSTALADOR

1. Baixe e instale o Inno Setup:
   https://jrsoftware.org/isdl.php

2. Após instalar, clique com o botão direito no arquivo "setup.iss" criado nesta pasta e escolha "Compile".

3. O instalador (InstaladorPonto.exe) será criado na pasta "installer".

OBSERVAÇÃO:
O arquivo "setup.iss" já está configurado para pegar o executável e o banco de dados da pasta "dist".
Certifique-se de que a pasta "dist" contém o "Ponto2.exe", "config.ini" e "database.db" atualizados antes de compilar.
